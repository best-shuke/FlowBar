FlowBar 现在使用同目录下的 mihomo 内核。这个文件不是程序，FlowBar 不会运行它：
它只让 FlowBar 0.5.0 到 0.8.2 的应用内更新认出新的安装包（这些版本会检查安装包里有没有
rill 内核），并让这些版本留下的卸载程序认出安装目录。

FlowBar now runs the mihomo core beside this file. This is not a program and is never run: it
only lets the in-app updater of FlowBar 0.5.0 to 0.8.2, which checks a package for a rill core,
recognise the new package, and lets the uninstaller those versions left recognise the
installation directory.
