### 修复和改进

- macOS 首次使用 TUN 时授权安装专用后台服务，后续连接、切换配置、退出后重开和重启后自动连接无需重复输入管理员密码。升级应用后首次连接需授权升级服务。
- macOS「测试延迟」改为菜单内按钮，点击后菜单保持展开，原地显示测试进度、延迟和超时结果。
- 内核日志提高到 debug，新增带毫秒时间戳的会话诊断，记录启动阶段、端口、授权服务、测速耗时与结果、停止请求和错误链。「打开日志」直接打开会话目录。
- 日志文件限制为 2 MiB，超限保留最近内容，继续只保留最近 5 次会话，避免长期占用磁盘。

后台服务只接受已验证用户和应用的会话请求，不保存管理员密码。卸载服务的方法见使用说明。
