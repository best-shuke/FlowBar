### 新功能

- 支持订阅链接：在「配置 → 从订阅链接导入…」或设置窗口的「导入配置…」里粘贴 `https://` 订阅链接，FlowBar 下载并检查 mihomo YAML 后保存为一份配置。
- 订阅自动更新：按服务器的 `profile-update-interval` 更新，默认每 24 小时；使用 `ETag` 条件请求，内容没变时不重新下载。也可以在「配置 → 更新订阅」里立即更新。
- 连接中的配置被自动更新时不会断线，菜单和设置窗口提示「订阅已更新，重新连接后生效」；手动更新会自动重新连接。设置窗口显示订阅上次更新的时间或失败状态。

### 安全

- 订阅只通过 HTTPS 下载，重定向也只允许 HTTPS；内容超过 16 MB、不是 UTF-8 或不能解析为 mihomo 配置时一律拒绝，原有配置保持不变。
- 订阅链接只保存在权限 0600 的 `settings.json`；错误提示只显示域名，不会写出链接中的密钥。
- 用本地文件替换订阅配置或删除配置时，同时停止它的自动更新。
