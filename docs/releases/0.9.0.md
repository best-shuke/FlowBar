### 内核换回 mihomo

- 安装包内置的内核从 rill 换回 [mihomo](https://github.com/MetaCubeX/mihomo) v1.19.33，使用 MetaCubeX 官方发布的二进制，下载时校验 SHA-256。导入的配置、节点、策略组和规则照常使用。
- rill 专有的 XPro 节点类型 mihomo 不支持，配置里有这类节点时，配置检查会报错，需要先删掉。
- 从 0.5.0 到 0.8.2 应用内更新照常可用。更新后第一次连接时，FlowBar 会停掉旧版本留下的 rill 内核再启动 mihomo。macOS 上用过 TUN 的话，第一次连接需要再授权一次，升级后台服务。
