### 修复和改进

- macOS 测速菜单在打开时预留完整结果宽度，异步返回后“超时”和延迟数字不再被裁切。
- 切换配置、连接完成、停止连接和更换节点后，已打开的节点菜单及时刷新。三个平台的设置页重新打开或获得焦点时都会更新配置列表和统计。
- Linux 托盘测速结果使用完整普通文本，兼容不同桌面面板的菜单布局；Windows 增加原生菜单“超时”文字和设置页刷新检查。
- 修复 DNS 使用独立旧策略组的问题。DNS 查询跟随当前节点选择，切换节点时释放旧的 DNS 连接，后续查询使用新节点。
- macOS、Linux 和 Windows 安装包统一构建包含 XPro 的 rill 内核，支持加载已有 XPro H2/WSS 节点。

各平台打包前运行 DNS 策略组切换及 XPro 加载验证；原生平台运行界面冒烟测试。手动运行 Release 工作流会生成草稿，推送版本标签时正式发布。
