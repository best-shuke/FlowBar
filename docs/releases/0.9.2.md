### 修复和改进

- VLESS / VMess 节点设置了 `smux.protocol: muxcool` 时，不再因 mihomo 报 `unknown protocol: muxcool` 导致整份配置无法启动。连接时关闭这层不受支持的多路复用，保留节点的普通连接；其他受支持的 smux 设置保持原样，原始 YAML 不会被修改。
- 修复 0.9.1 的 TUN 防回流规则影响同一服务器上其他服务的问题：自动直连只匹配代理服务端口，不再覆盖整个服务器 IP。SSH 等其他端口继续遵循配置中的路由，同时支持 IPv4、IPv6、域名和端口跳跃范围。
- 服务器 IP 规则对应的节点或策略组不存在时，如果配置中存在 `proxy`，保留该规则并改用 `proxy`；对应项仍存在时保持原目标。回退适用于精确目标 IP（IPv4 `/32`、IPv6 `/128`），不会因节点暂时超时而切换。兼容处理详情记录在会话日志里。
- 新增真实 mihomo 回归检查，覆盖 Mux.Cool 配置兼容、代理端口与同 IP 其他端口的分流，以及对应节点缺失时的 `proxy` 回退。
