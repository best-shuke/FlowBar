### 修复和改进

- macOS TUN 后台服务回收已退出的会话监督进程。此前每次断开 TUN 都会留下一个僵尸进程，长期使用会持续累积。
- 内核监督进程意外退出（例如被系统强制结束）时，FlowBar 会检测到内核已停止并提示，不再一直显示已连接；停止连接时也不必再等待超时。
- 导入与已有配置仅大小写不同的 YAML 并选择「替换」时，替换原有配置。此前 Linux 上会多出一份配置，macOS 和 Windows 上当前配置在列表中不显示为选中。
- Windows 开机自启注册表值过长时，读取登录项状态不再导致程序崩溃。
- `install.sh` 生成的应用启动项正确转义路径中的反斜杠，与应用内的登录自启项一致。
